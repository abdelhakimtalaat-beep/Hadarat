# إعداد «دليل الحضرات» مع قاعدة بيانات

1. أنشئ حسابًا مجانيًا على supabase.com ثم **New project** (اختر أقرب منطقة، واحفظ كلمة مرور القاعدة).
2. من **SQL Editor** الصق محتوى `schema.sql` كاملًا واضغط Run.
3. من **Authentication > Users > Add user** أنشئ حساب المشرف (بريد وكلمة مرور، واختر Auto Confirm).
4. في SQL Editor شغّل السطر الأخير المعلّق في `schema.sql` بعد وضع بريد المشرف، ليصبح الحساب مشرفًا.
5. من **Project Settings > API** انسخ **Project URL** و **anon public key** وضعهما في `config.js`.
6. ارفع هذا المجلد على Netlify Drop (app.netlify.com/drop) فتحصل على الرابط العام.
7. افتح الرابط ← تبويب «المزيد» ← «دخول المشرفين» ← سجّل الدخول، فتظهر أزرار «تعديل» و«إضافة حضرة».

لإضافة مشرف آخر: أنشئ له مستخدمًا (الخطوة 3) ثم أضفه بالسطر المعلّق (الخطوة 4).
النسخ الاحتياطي: من Supabase > Table Editor > hadarat > Export to CSV.
التكلفة: الخطة المجانية تكفي هذا الحجم بكثير، لكن المشاريع المجانية تتوقف بعد أسبوع من عدم النشاط، فافتح التطبيق مرة أسبوعيًا على الأقل.
